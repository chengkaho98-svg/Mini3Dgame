# 🍬 糖糖大亂鬥 SUGAR RUSH ROYALE

致敬《Fall Guys》嘅 3D 糖果物理闖關賽跑網頁遊戲。5 大主題關卡、20 種機關、
本地 **4 人鍵盤對戰（直切分屏）**＋AI 機械人補位至 10 人混戰。

![cover](cover.png)

## 🎮 點樣開始

```bash
node server.js
# 開瀏覽器去 http://127.0.0.1:8077/
```

> 需要網絡連線（three.js 由 CDN 載入）。任何靜態 server 都得，例如
> `python -m http.server 8077`。

## ⌨️🎮 控制表

| 玩家 | 移動 | 跳躍 | 撲倒 |
|------|------|------|------|
| P1 | W A S D | Space | 左 Shift |
| P2 | ↑ ↓ ← → | 右 Ctrl / Enter / Num0 | 右 Shift / `/` |
| P3 | I J K L | U | O |
| P4 | T F G H | Y | R |

- 四人共用一個鍵盤：撳所屬移動鍵即時加入（P2 方向鍵／P3 IJKL／P4 TFGH）
- 按色圓圈換顏色；✕ 移除；人類上限 4 位
- 🤖 **機械人數量自由調校**（0–9 或自動補至 10 人）
- 🖥 **直切分屏（vertical split）**：N 人 = N 個左右並排全高欄，
  每位玩家獨立追蹤鏡頭＋分隔線；P1 滑鼠轉視角（其他人固定向前）；Esc 暫停

## 🧠 技術

- **three.js 0.160**（CDN ES module）＋ ACES 色調映射＋ UnrealBloom 泛光
- **固定 120Hz 步長物理**：膠囊 vs AABB、逐步解算，40–60 m/s 極速測試零穿牆
- 速度手感：最高 6.2 m/s、跳躍射程 ≈4.1m（高度感知彈道），撲倒 11 m/s
- 機關物理保證：擺錘/風車葉/壓碎機頭/滾球全部掃過地板上方、永不穿板；
  彈床任何接觸即彈（0.45s 冷卻）
- 斷橋＝真正挖空嘅路面（分段道路 slab），水面著色器＋缺口水光面板＋ JUMP 地貼
- 角色：膠囊身體＋手腳跑步循環、跳躍／撲倒／跌倒動畫、名牌
- 10 人相互碰撞推擠；衝線排名、星星評價、最佳時間（localStorage）
- AI 機械人：方向採樣＋威脅場評分、彈道跳距計算嘅斷橋模式、
  移動平台接送、圓盤反旋轉駕駛、風扇氣流運用、掃臂時機衝刺
- 隱藏分頁 watchdog（rAF 節流後備循環）
